# Referencia elegida para Rutinas

Fecha: 13 de octubre de 2026.

El usuario eligió [este boceto](rutinas-elegida-2026-10-13.png) como referencia para el listado de Rutinas. La copia conserva los bytes de la imagen adjunta. Se cierra la ronda de correcciones de esta pantalla mediante Gemini.

Se conserva la distribución: hora a la izquierda, nombre y mensaje en el centro, interruptor a la derecha, seguimiento debajo de la activación y acciones Editar/Eliminar al pie. La navegación es Inicio, Rutinas, Contenido y Agenda.

Los retoques propuestos para la implementación son insertar el [logo oficial](../referencias/logo-teo.png), usar «Organizá recordatorios para acompañar su día» y presentar Editar/Eliminar como controles secundarios cómodos de tocar, sin subrayado y con iconos discretos. No se modifica el boceto elegido para resolver estos detalles.

Se recibió [esta propuesta de Nueva rutina](nueva-rutina-propuesta-2026-10-13.png), con los tres campos del formulario actual: nombre, hora y mensaje. El mensaje vacío utiliza una frase automática; una nueva rutina se agrega activada. La propuesta todavía no tiene aprobación explícita del usuario. Para la implementación se plantea señalar el nombre obligatorio, permitir varias líneas en el mensaje y conservar los datos si falla la validación o el guardado. Anticipación y mensajes de transición/logro siguen pendientes de decidir como opciones editables.

Editar rutina puede reutilizar el formulario, con datos precargados, título «Editar rutina» y botón «Guardar cambios». No debe conservar la aclaración de alta «La rutina se agregará activada»: editar conserva el valor de activación existente.

Se recibió [esta referencia del diálogo de eliminación](rutinas-dialogo-eliminar-referencia-2026-10-13.png). El usuario señaló que el fondo está mal y aceptó continuar. Solo se toma como referencia el diálogo centrado, su pregunta con el nombre de la rutina y las acciones Cancelar/Eliminar. El fondo inventado, su encabezado, sus tarjetas y su navegación no forman parte del diseño elegido. En la implementación se superpone el diálogo al listado de Rutinas elegido, con atenuación temporal.

La elección de este boceto autoriza usarlo como referencia de diseño. No se modificó código de la aplicación.
